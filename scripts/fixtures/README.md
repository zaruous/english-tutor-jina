# 검증 픽스처

## ko-misread-8s.wav — 한국어 '오독' 음성 (7.99초, 22.05kHz mono)

발음 평가의 **오독 저점수 단정**(플랜 10 §5-3, `verify-pronunciation.mjs` B 절)용 픽스처.
영어 목표 문장에 대해 이 한국어 음성을 넣으면 점수가 확실히 낮아야 한다 — 캘리브레이션 경고에
대한 최소 방어이자, "무슨 소리를 넣어도 후한 점수"가 나오는 회귀를 잡는다.

- 내용: "안녕하세요. 오늘 회의는 목요일 오후로 옮겨졌습니다. 회의실은 삼층 작은 방으로 예약해 주세요."
- 출처: espeak-ng 한국어 음성(`espeakng-loader` PyPI 리소스)으로 **오프라인 합성**.
  위키미디어 등 실음성 저장소가 CI/컨테이너 프록시에서 차단돼 합성으로 대체했다 —
  실제 사람 음성으로 바꾸면 더 좋은 픽스처가 된다(10초 이내, 개인정보 없는 소스로).
- 사용 (사이드카 기동 후):
  `node scripts/verify-pronunciation.mjs --bad scripts/fixtures/ko-misread-8s.wav`
  (`--good` 을 생략하면 espeak-ng 로 올바른 낭독을 합성해 비교한다)
